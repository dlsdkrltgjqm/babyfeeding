# 이유식 기록장 🍼

우리 아기 이유식 일정과 식단을 기록·관리하는 모바일 친화 웹앱입니다. 별도 설치 없이 `index.html` 하나로 동작하며, 데이터는 브라우저(localStorage)에 자동 저장됩니다.

## 주요 기능

- **📅 캘린더** — 월 단위로 전체 이유식 일정을 한눈에. 기록이 있는 날과 개수를 표시하고, 날짜를 눌러 그날의 재료를 추가·수정·삭제합니다.
- **📖 내역** — 모든 기록을 날짜별로 묶어 최신순으로 보고, 재료 이름으로 검색합니다.
- **📊 통계** — 주간/월간으로 사용한 재료와 횟수를 모아 보고, **영양소별**(곡물·탄수화물 / 단백질 / 채소 / 과일 / 유제품·기타)로 구분해 비율 막대와 순위로 보여줍니다.
- **재료 입력** — 49종의 빠른 선택 칩(+직접 입력), 양·단위, 반응(양호/이상, 알레르기 관찰), 메모 기록.
- **📁 데이터 관리** — 날짜가 들어간 파일명으로 내보내기(백업)와 파일/붙여넣기로 가져오기(복원). 병합 또는 전체 교체 지원.
- 모바일 대응 반응형 레이아웃, 라이트/다크 테마.

## 사용 방법

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 데이터는 사용하는 브라우저에 저장되므로, 기기를 바꿀 때는 데이터 관리의 내보내기/가져오기로 옮기세요.

### GitHub Pages로 보기

저장소 **Settings → Pages**에서 브랜치를 `main`으로 지정하면 `https://dlsdkrltgjqm.github.io/babyfeeding/` 주소로 접속해 바로 쓸 수 있습니다.
