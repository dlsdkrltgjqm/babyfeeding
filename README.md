# 이유식 기록장 🍼

우리 아기 이유식 일정과 식단을 기록·관리하는 모바일 친화 웹앱입니다. 설치 없이 `index.html` 하나로 동작해요.

## 저장 방식 (자동 전환)

- **로컬 저장** — GitHub Pages 등 일반 주소로 열면 데이터가 **이 브라우저(localStorage)** 에 저장됩니다. 기기마다 따로 보관돼요.
- **NAS 저장 + 동기화** — 같은 주소에 **PocketBase 백엔드(`/api`)** 가 붙어 있으면(예: 집 NAS에서 서빙) 자동으로 **서버 저장 + 기기 간 동기화** 모드로 전환됩니다.
- 백엔드가 응답하면 NAS 모드, 응답이 없으면 로컬 모드로 **자동 판별**합니다. 앱에는 서버 주소가 하드코딩되어 있지 않아요(접속한 주소를 그대로 사용).

데이터 관리(📁) 화면 상단에 현재 저장 모드(🟢 NAS / 💾 로컬)가 표시됩니다.

## 주요 기능

- **📅 캘린더** — 월 단위로 전체 일정을 한눈에. 날짜를 눌러 재료를 추가·수정·삭제.
- **📖 내역** — 모든 기록을 날짜별로, 재료 이름으로 검색.
- **📊 통계** — 주간/월간 사용 재료·횟수를 **영양소별**로 구분(비율 막대 + 순위).
- **📋 식단표** — 시기별(초기·중기) 추천 식단표. 시작일을 고르면 각 날짜의 재료를 **‘+기록’으로 바로 담기**(오전/오후 따로, 이미 담은 날은 ✓ 표시).
- 재료 빠른 선택, 반응(알레르기 관찰)·메모, **내보내기/가져오기(백업)**, 전체 삭제.
- **PWA** — 홈 화면에 추가해 앱처럼 사용, 라이트/다크 테마.

## 파일

- `index.html` — 앱 (단일 파일)
- `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon-32.png` — PWA 매니페스트/아이콘
